# Les gabarits

Cinq fichiers d'exemple, un par sorte. Le dossier commence par `_` et n'est
donc pas une sorte : rien d'ici n'est scanné, routé ni publié.

Pour écrire un atome : copier le gabarit de sa sorte dans le dossier de cette
sorte, le renommer avec son slug, remplir les cases. Le gabarit n'est pas une
contrainte de style, c'est l'anti-page-blanche.

Mode d'emploi complet : `docs/systeme-de-contenu.md`.
