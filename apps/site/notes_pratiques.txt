Tailles d'images :
- ne rien pré-redimensionner : le build fabrique six largeurs par image
  (96, 256, 360, 640, 1080, 1600) dans public/images-opt, et le site y renvoie
- déposer les sources dans public/images, à leur taille de travail
- une variante n'agrandit jamais sa source, et ne la remplace pas si le
  réencodage ressort plus lourd
- public/images-opt n'est pas versionné : il se refabrique à chaque build
  (56 s à froid, instantané ensuite)

server {
    listen 443 ssl;
    server_name tracking.thelocomotionlab.com;

    ssl_certificate /etc/letsencrypt/live/tracking.thelocomotionlab.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/tracking.thelocomotionlab.com/privkey.pem;

    # Interface Traccar normale (requiert login)
    location / {
        proxy_pass http://127.0.0.1:8082/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    #  API publique sans login, avec token auto-injecté
    location /api/public/ {
        # Réécriture de l’URL vers l’API réelle
        rewrite ^/api/public/(.*)$ /api/$1 break;
        proxy_pass http://127.0.0.1:8082;

        #  Token API Traccar : NE JAMAIS écrire le token en clair ici.
        #  Valeur injectée au déploiement depuis la variable d'environnement
        #  $TRACCAR_API_TOKEN (secret du VPS) — cf. docs/secrets.md.
        #  Ex. via envsubst dans un template de conf nginx versionné sous infra/.
        proxy_set_header Authorization "Bearer ${TRACCAR_API_TOKEN}";

        # En-têtes de proxy standard
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # ---  Autorisation CORS (pour appels depuis ton front React / site web) ---
        add_header 'Access-Control-Allow-Origin' '*' always;
        add_header 'Access-Control-Allow-Methods' 'GET, POST, PUT, DELETE, OPTIONS' always;
        add_header 'Access-Control-Allow-Headers' 'Origin, Content-Type, Accept, Authorization' always;
        add_header 'Access-Control-Allow-Credentials' 'true' always;

        # Réponse immédiate aux requêtes préflight (OPTIONS)
        if ($request_method = OPTIONS) {
            add_header 'Access-Control-Allow-Origin' '*' always;
            add_header 'Access-Control-Allow-Methods' 'GET, POST, PUT, DELETE, OPTIONS' always;
            add_header 'Access-Control-Allow-Headers' 'Origin, Content-Type, Accept, Authorization' always;
            add_header 'Access-Control-Max-Age' 86400;
            return 204;
        }

        # Empêche Traccar d’imposer des cookies de session
        proxy_hide_header Set-Cookie;
        proxy_hide_header WWW-Authenticate;
    }

    #  Redirection HTTP -> HTTPS
    error_page 497 https://$host$request_uri;
}

Ordre des blocs d'une page aventure :
- la page EST la liste `sections:` du frontmatter, dans cet ordre exact
- pour déplacer un bloc, déplacer son entrée dans cette liste ; rien d'autre
- l'ordre du corps MDX ne compte pas : un <SectionLibre id="x"> est rattaché
  par son id à l'entrée `- type: libre / id: "x"`, où qu'il soit écrit
- la numérotation (01, 02…) et le sommaire suivent tout seuls
- les ancres (#genese-du-projet) viennent de l'id ou du titre, pas du rang :
  un lien déjà partagé continue de tomber au bon endroit après un déplacement
- aucun type n'est obligatoire ni contraint à une position : le récit peut être
  en tête, la trace en fin, une page peut n'avoir que trois blocs

Nutrition embarquée depuis LighterPack :
- dans la fiche d'aventure, la section nutrition s'écrit
    - type: nutrition
      titre: "Nutrition embarquée"
      ref: "tour-des-ecrins"      # le nom du .csv, sans l'extension
- le tableau est produit depuis la catégorie de nourriture du paquetage
  (une catégorie nommée Alimentation, Nutrition, Nourriture ou Ravitaillement)
- LighterPack n'a pas de champ d'énergie : les calories s'écrivent dans la
  DESCRIPTION de l'article, par exemple « 615 kcal » ou « gruau, 615 kcal »
- la valeur est comptée PAR UNITÉ, comme la masse : 3 gruaux à 615 kcal = 1 845
- deux colonnes en sortent, kcal/unité et kcal total ; elles n'apparaissent que
  si au moins un article déclare son énergie
- la dernière ligne d'un tableau, si elle commence par « Total », se lit en gras
- sans .csv ou sans catégorie de nourriture, la section n'affiche que son texte
